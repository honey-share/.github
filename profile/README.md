## 🍯 Featured Project

# HoneyShare

### Fast. Simple. Temporary.

**Share files without the unnecessary complexity.**

</div>

HoneyShare is a lightweight file-sharing application built around a simple workflow:

```text
📤 Upload
   ↓
🔢 Get 5-Digit Code
   ↓
📲 Share Code
   ↓
📥 Download
   ↓
🗑️ Temporary Transfer
```

### ✨ Highlights

* 🔐 No mandatory account
* 🔢 Simple 5-digit transfer codes
* 📦 Temporary file sharing
* 📱 Responsive web experience
* ⚡ Fast and minimal workflow
* ☁️ Supabase-powered backend
* 🌐 Vercel deployment
